# Домашняя работа №2

Программа читает данные из `Corp_Summary.csv` и формирует отчёты по департаментам.

## Требования

- Python 3.
- Дополнительные библиотеки устанавливать не нужно: используется стандартный модуль `csv`.

## Запуск

Из корневой папки репозитория перейдите в папку задания и запустите программу:

```bash
cd homework_2
python3 main.py
```

Файл `Corp_Summary.csv` должен находиться в папке `homework_2`.

## Выбор отчёта

Режим задаётся аргументом функции `main` в конце файла `main.py`:

```python
if __name__ == "__main__":
    main(3)
```

Доступные режимы:

- `main(1)` — вывести в консоль иерархию департаментов и входящих в них отделов.
- `main(2)` — вывести в консоль сводку по департаментам: количество сотрудников, минимальную, максимальную и среднюю зарплату.
- `main(3)` — сохранить сводку в файл `departament_summary.csv`.

По умолчанию выбран режим `3`. Чтобы изменить режим, замените число в вызове `main(3)` и запустите программу снова. Передача режима через командную строку пока не поддерживается.

## Результат

При запуске по инструкции файл `departament_summary.csv` создаётся в папке `homework_2`. Если такой файл уже существует, он перезаписывается.

Отчёт содержит столбцы:

- `Департамент`;
- `Количество`;
- `Минимум`;
- `Максимум`;
- `Средняя`.
