# Анализ Нобелевских лауреатов
Исследование страны рождения, возраст получения первой премии и гендерное распределение Нобелевских лауреатов.

## Подготовка
Для запуска нужен Python 3 и Jupyter Notebook либо VS Code
с расширениями Python и Jupyter.
Код анализа использует только стандартную библиотеку Python.
Для запуска через Jupyter Notebook установите:
python3 -m pip install notebook
Скачайте файл laureates.json из сообщения преподавателя
и положите рядом с ноутбуком. Название файла менять не нужно.
Исходные данные не включены в репозиторий.

## Запуск
Откройте laureates_countries_task (4).ipynb.
Выберите ядро Python и выполните все ячейки сверху вниз.

## Файлы проекта
- json_dict_processing.py — обработка вложенных словарей.
- prizes_configs.py — конфиг премий.
- laureates_configs.py — конфиги людей и организаций.
- dataset_helpers.py — проверка данных, фильтрация и группировка.
- aggregations.py — подсчёты, статистика и топ-N.
- atribute_manager.py — добавление вычисляемых полей.
